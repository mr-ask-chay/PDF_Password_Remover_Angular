## Recommendation

Prioritize organic acquisition for operations that are already implemented and safe to describe. Keep current ads off until the account, consent, placement, and live request conditions are verified. Do not add payments until user evidence supports a specific paid capability. Keep the developer API outside paid promotion until its backend is reviewed. No revenue estimate is responsible without traffic, fill, pricing, cost, and conversion data.

### Guardrails for any future measurement

- Never send PDF bytes, file names, passwords, extracted text, metadata, or a stable/document-derived identifier to analytics, ads, payment systems, or logs.
- Prefer aggregate page route and operation-completed counters with no user or file identifier. Respect consent and user choice where required.
- Keep local file processing and downloads working if ad/analytics scripts are blocked, unavailable, or consent is denied.
- Do not put ads next to file pickers, password inputs, process controls, result links, or downloads. Do not mimic buttons or interleave ads in a flow.
- Do not market unsupported OCR, redaction, repair, signing, Office conversion, AI, or translation.
